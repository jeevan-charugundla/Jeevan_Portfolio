# Jeevan Charugundla Portfolio

This is a premium Neo-Brutalist portfolio showcase.

## Tech Stack
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS (Modern CSS properties)
- **Design System**: Neo-Brutalist aesthetics (High contrast, bold shadows, vibrant colors)

## Project Structure
- `index.html`: Main portfolio entry point.
- `Assets/`: Images, icons, and resume files.
- `.gitignore`: Repository cleanup and artifact exclusion.

## Deployment
The portfolio is designed for static hosting (GitHub Pages, Vercel, or Netlify).
